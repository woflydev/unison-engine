# Keyboard map

| Shortcut | Action | Status |
|---|---|---|
| Cmd-K | Quick switcher | done |
| Cmd-Shift-I | Inbox (Cmd-I is italic in the composer) | done |
| Cmd-0 | Direct Messages | done |
| Ctrl-1..9 | Switch account | done |
| Cmd-Shift-N | Add account | done |
| Cmd-Shift-M / Cmd-Shift-D | Mute / deafen | done |
| Esc | Dismiss unread bar and NEW separator | done (while the bar shows) |
| Alt-Up / Alt-Down | Previous / next channel | done |
| Alt-Shift-Up / Alt-Shift-Down | Previous / next unread channel | done |
| Cmd-[ / Cmd-] | History back / forward | done |
| Cmd-Alt-Up / Cmd-Alt-Down | Previous / next server | done |
| Cmd-F | Focus search | done |

Hold Shift over a message: the hover bar swaps to Reaction, Edit, Reply, Forward, Pin, Copy Text, Copy Link, Copy ID, Delete (set recalled from the official client, not captured; Mark Unread still missing).
